# blitzbreak

HAL東京 4年次チーム制作(10人 / 約3か月)のUnity作品。

## 担当範囲
- 建物の破壊挙動プログラム
- オプション全体(サウンド/操作/グラフィックのタブUI、感度・FPS上限・画質設定)
-バトルポーズプログラム
-SceneTransition
- タイトル画面、スコア画面遷移のプログラム（UI配置含む）
- 敵・プレイヤーのバレットプログラム
- 建物周辺オブジェクト(電灯・ゴミ箱など)の配置
- マップ中心オブジェクトを円弧状に配置するプログラム
- AudioManager

## 開発環境
Unity / C#
